# Database Schema Documentation

This document describes the PostgreSQL database schema for the ArmourLink PPE Compliance and Workforce Management System. The schema is configured and managed using Prisma ORM.

## Tables & Relations

### 1. `User` (User Accounts)
Holds administrative and supervisor accounts for portal login.
- **Fields**:
  - `id` (String, Primary Key, UUID): Unique user identifier.
  - `email` (String, Unique): User's login email.
  - `passwordHash` (String): Hashed password (bcrypt).
  - `name` (String): Display name of the user.
  - `role` (Enum `Role`): Can be `ADMIN` or `SUPERVISOR`.
  - `siteId` (String, Foreign Key, Nullable): References `Site.id`. Indicates the site a supervisor monitors. Null for Admins.
  - `createdAt` (DateTime): Timestamp of creation.
  - `updatedAt` (DateTime): Timestamp of last edit.
- **Foreign Keys**:
  - `siteId` -> `Site(id)` (On Delete: `SetNull`).

### 2. `Site` (Client Sites)
Defines working zones/locations where workers are positioned.
- **Fields**:
  - `id` (String, Primary Key, UUID): Unique site identifier.
  - `name` (String, Unique): Distinct name of the site (e.g., "Warehouse North").
  - `location` (String): Descriptive address/sector.
  - `createdAt` / `updatedAt` (DateTime).

### 3. `Worker` (Seeded Workers)
Maintains profiles of all 100 workers imported from the Excel sheet.
- **Fields**:
  - `id` (String, Primary Key): Worker IDs matching Excel format (e.g., `WRK0001`).
  - `name` (String): Full name of the worker.
  - `jobProfile` (String): Job role (e.g. "Forklift Operator").
  - `department` (String): Department (e.g. "Production").
  - `mobileNumber` (String): Worker's phone contact.
  - `aadharNumber` (String): Government identification string.
  - `siteId` (String, Foreign Key): Assigned working site.
- **Foreign Keys**:
  - `siteId` -> `Site(id)` (On Delete: `Cascade`).

### 4. `Violation` (Safety Incidents)
Stores safety equipment non-compliance alerts generated by the IoT simulation.
- **Fields**:
  - `id` (String, Primary Key, UUID): Unique incident identifier.
  - `workerId` (String, Foreign Key): References `Worker.id`.
  - `type` (String): Type of equipment missing (e.g. "No Helmet", "No Safety Vest").
  - `timestamp` (DateTime): Time the violation occurred.
  - `severity` (Enum `Severity`): Priority level of safety issue (`LOW`, `MEDIUM`, `HIGH`).
  - `isAcknowledged` (Boolean): Flag representing if the supervisor has resolved the alert.
  - `acknowledgedById` (String, Foreign Key, Nullable): References `User.id` (who acknowledged the alert).
  - `acknowledgedAt` (DateTime, Nullable): Time resolved.
- **Foreign Keys**:
  - `workerId` -> `Worker(id)` (On Delete: `Cascade`).
  - `acknowledgedById` -> `User(id)` (On Delete: `SetNull`).
